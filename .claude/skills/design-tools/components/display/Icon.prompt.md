Monochrome Lucide glyph that inherits text color — use it for every icon in Svk Beslutsök UI rather than inline SVG.

```jsx
<Icon name="scale" size={18} color="var(--burgundy-600)" title="Authority" />
```

Names are Lucide kebab-case ids. House set: `search`, `scale`, `book-open`, `gavel`, `file-text`, `bookmark`, `quote`, `filter`, `chevron-down`, `arrow-up-right`, `check`, `x`, `plus`, `sparkles`, `history`, `folder`, `link-2`, `download`.
